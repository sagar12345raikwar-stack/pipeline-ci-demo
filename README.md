# Pipeline CI Demo

This is a simple Java Maven project used to demonstrate Jenkins Pipeline as Code.

## Project Structure

```text
pipeline-ci-demo
├── src
│   └── main
│       └── java
│           └── App.java
├── pom.xml
├── Jenkinsfile
└── README.md
```

## Build

```bash
mvn clean package
```

## Run

```bash
java App
```
